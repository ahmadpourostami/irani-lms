# Irani LMS

یک افزونه LMS بومی برای وردپرس با تمرکز بر تجربه کاربری فارسی، RTL، تومان، تاریخ شمسی و زیرساخت پایدار پرداخت‌های ایرانی.

## هدف

Irani LMS یک ترجمه یا Fork از LearnPress نیست. LearnPress و سایر LMSها مرجع تحلیل قابلیت‌ها هستند و محصول با معماری مستقل توسعه داده می‌شود.

## اصول

- هسته مستقل و ماژولار
- API-first برای آمادگی اپلیکیشن موبایل
- Commerce و Payment مستقل از Course
- درگاه پرداخت قابل توسعه و مناسب سرویس‌های ایرانی
- RTL و بومی‌سازی فارسی در سطح هسته
- قابلیت توسعه بدون وابستگی به WooCommerce
- PHP 8.1+

## معماری اولیه

```text
Irani LMS
├── Course
├── Learning
├── Enrollment
├── Assessment
├── Certificate
├── Commerce
│   ├── Order
│   └── Payment
├── Communication
└── API
```
